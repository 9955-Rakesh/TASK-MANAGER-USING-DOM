# DOM Explorer — Task Manager

A **Task Manager built from scratch using JavaScript DOM manipulation** to practice creating dynamic and interactive web interfaces.

This project is part of my **DOM Explorer** learning journey, where I’m focusing on understanding how JavaScript interacts with HTML elements, events, and the UI.

## 🚀 Features

* ➕ Add tasks
* ✏️ Edit tasks
* 🗑️ Delete tasks
* 🔄 Dynamic task updates
* 🖱️ DOM manipulation
* ⚡ JavaScript event handling

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* DOM Manipulation

## 📚 What I'm Learning

Through this project, I'm practicing:

* Selecting and manipulating DOM elements
* Handling user events
* Creating and updating elements dynamically
* Managing task data
* Building interactive UI with JavaScript
* Understanding how real-world interfaces work
